# Louvre de Raul

Estudo de arquitetura em Three.js: uma versão simplificada e navegável da Grande Galerie do Louvre, com abóbada de berço, claraboias e arcos sobre colunas duplas. Proporções aproximadas.

Os quadros ficam vazios para receber desenhos: toque em um quadro ou use "Adicionar desenhos". As imagens ficam só no aparelho de quem navega.

## Controles

- Celular: polegar esquerdo anda, arrastar no resto da tela olha em volta.
- Computador: clique para olhar com o mouse, WASD ou setas andam, Shift corre, Esc solta o mouse.

Página única (`index.html`), Three.js 0.170 via CDN, sem build.
